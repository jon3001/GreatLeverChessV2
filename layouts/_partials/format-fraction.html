{{- /* Chess-style score fraction: a whole number prints bare ("4"); a half-point gets the ½ glyph appended to the whole part ("2½") rather than a decimal ("2.5"). Takes a number as the partial's context, returns the formatted string. Not reused from the board-level result mapping in fixture-boards.html — that's a fixed six-value enum (home_win/draw/etc.) looked up against a fixed string table, no arithmetic involved. This is doing real division-derived arithmetic on an open-ended team score (home_score/away_score), which needed writing once rather than being available already. Zero whole part is a special case: "0½" reads as a leading zero ("4½-0½"), not as chess notation, which never writes one — a bare "½" is the correct form for exactly half a point ("4½-½"). */ -}} {{- $n := . -}} {{- $whole := math.Floor $n -}} {{- if eq (sub $n $whole) 0.5 -}} {{- if eq $whole 0.0 -}} {{- "½" -}} {{- else -}} {{- printf "%d½" (int $whole) -}} {{- end -}} {{- else -}} {{- printf "%d" (int $n) -}} {{- end -}}
